This is a repository containing both source Markdown files and HTML files
generated out of them.

There are several subdirectories (listed in pskov.cfg) that form site parts.

I mostly work with news/en and news/ru, these are localized versions of tween
articles in both English and Russian correspondingly

Each Markdown file has a specific format in both the name and in the internal
structure. Internal Markdown structure has (in the beginning of a file)
properties of Pelican static site generator. Though, this whole site
is managed/generated by PSKOV static site generator.

Thus, agent, when I ask you to create a new stub page, you should:
* locate the source Markdown file
* increment (in memory) the date by one month
* created said stub file, one for news/en and one for news/ru, with the matching name
